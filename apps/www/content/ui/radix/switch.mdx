---
title: Switch
description: An accessible toggle switch component built on Radix UI with spring layout physics and full customization.
author:
  name: Axyl
  url: https://github.com/Axyl1410
intent: Toggle an independent binary setting or preference.
role: switch
a11yConstraints:
  - Preserve the switch role, label association, and keyboard toggling via Space or Enter.
  - Never use a switch for navigating pages or submitting immediate destructive actions without confirmation.
motionEngine: Motion flex layout spring animation with stiffness 500 and damping 30.
compositionRules:
  - Pair with a visible label and optional description text.
  - Support full class override on root container, thumb, and label elements.
compositionRecipes:
  - name: radix-settings-toggle
    description: Control a user preference in an account or system settings view.
    components:
      - radix/switch
    constraints:
      - Keep the label clickable and clearly describe the effect of enabling the switch.
---
