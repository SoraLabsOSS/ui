## Usage

```tsx
import { TextFlip } from "@/components/sora-ui/texts/text-flip";

export default function Page() {
  return (
    <TextFlip
      className="font-semibold text-sm uppercase tracking-tight"
      text="HELLO@SORALABS.STUDIO"
    />
  );
}
```

Render as an anchor link and reverse the flip direction:

```tsx
<TextFlip
  as="a"
  href="mailto:hello@soralabs.studio"
  reverse
  text="HELLO@SORALABS.STUDIO"
/>
```

Keep the flipped state on mouse leave instead of flipping back:

```tsx
<TextFlip flipOut={false} stagger={0.04} text="STAY FLIPPED" />
```

## When to Use

Use `TextFlip` for interactive links, nav items, and footer contacts where a tactile per-character 3D flip reinforces hover feedback without shifting layout. It differs from [Rolling Text](/motion/rolling-text), which plays a one-time scroll-triggered slot reveal, and [Text Roll](/motion/text-roll), which transitions between changing string values.

## Accessibility

The full string is exposed via `aria-label` on the root element while the per-character 3D glyph spans are marked `aria-hidden`, so screen readers announce the text cleanly once. When `prefers-reduced-motion: reduce` is enabled, `TextFlip` skips the 3D flip and renders static text.
