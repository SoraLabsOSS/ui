Sora UI is preparing to migrate to a new official domain: **`ui.soralabs.studio`**.

As our component registry, primitives collection, and CLI tools continue to grow, moving to `soralabs.studio` unites the entire Sora Labs open-source ecosystem under a cleaner, more dedicated home.

This post serves as an advance announcement outlining what will change, our upcoming rollout timeline, and how we are ensuring zero disruptions for your existing projects.

## What is changing

### 1. New Official Web Address
- **Upcoming Domain:** `https://ui.soralabs.studio` *(currently in DNS setup & provisioning)*
- **Current Active Domain:** `https://ui.soralabs.io.vn`

Once the new domain is fully live and DNS propagation finishes, all documentation, component showcases, interactive catalogs, and API references will transition over.

### 2. Seamless 301 Redirects
You won't need to worry about broken bookmarks or external links. Every existing URL on `ui.soralabs.io.vn` — from individual primitive pages (`/motion/*`, `/ui/*`) to catalog layouts (`/catalog/*`) and blog articles (`/blog/*`) — will permanently redirect (HTTP 301) to its exact counterpart on `ui.soralabs.studio`.

### 3. CLI & Registry Compatibility
Your local workflow and CI/CD pipelines will continue to work without interruption:

- **Sora CLI:** `npx @soralabsoss/sora-cli add <component>` will automatically resolve against the new endpoints once the switchover occurs.
- **shadcn/ui CLI:** `npx shadcn@latest add @soralabs/<component>` will resolve through automatic HTTP redirects.
- **MCP Server:** Tools querying docs and registry metadata will route directly to the updated base URL.

```bash
# Both install commands remain fully supported
npx @soralabsoss/sora-cli add text-effect
npx shadcn@latest add @soralabs/text-effect
```

## Migration Timeline

- **Phase 1 (Upcoming / In Preparation):** Infrastructure setup, SSL certificate issuance, and registry routing validation for `ui.soralabs.studio`.
- **Phase 2 (Planned):** Primary DNS switchover and global 301 redirect deployment for all incoming traffic from `ui.soralabs.io.vn`.
- **Phase 3 (Final):** Updating repository documentation, npm package links, and social metadata.

We expect to complete Phases 1 through 3 over the coming week.

## What you should do

For now, **no immediate action is required**. Everything continues to run normally on `ui.soralabs.io.vn`.

When the migration completes:
1. **Update Bookmarks:** Switch your saved links to `ui.soralabs.studio`.
2. **Update Hardcoded References:** If you maintain internal starter kits or docs referencing `ui.soralabs.io.vn`, update them to the new domain.

If you have questions or feedback regarding the upcoming move, feel free to open a discussion on [GitHub](https://github.com/SoraLabsOSS/ui) or join our [Community Hub](https://github.com/SoraLabsOSS/sora-ui-community).
