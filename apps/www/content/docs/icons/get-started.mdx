Our animated icons come from [Reicon](https://reicon.dev/) — [Lucide Icons](https://lucide.dev) animated with [Motion](https://motion.dev).

<Callout type="warn">
  **Note:** The animated icons are in **beta**. You may encounter bugs.
  Recurring changes will take place, and some props may be added or removed. We
  recommend that you update the wrapper regularly.
</Callout>

## Installation

### Icon Wrapper

You need to install the icon wrapper component to use the animated icons.

<ComponentInstallation name="icons-icon" />

### Icons

<CodeTabs
  codes={{
    npm: `npx shadcn@latest add @soralabs/icons-[icon-name]`,
    pnpm: `pnpm dlx shadcn@latest add @soralabs/icons-[icon-name]`,
    yarn: `npx shadcn@latest add @soralabs/icons-[icon-name]`,
    bun: `bun x --bun shadcn@latest add @soralabs/icons-[icon-name]`,
  }}
/>

## Basic Usage

### Icon

```tsx
<Chevrons animateOnHover />
```

### Icon with AnimateIcon wrapper

```tsx
<AnimateIcon animateOnHover>
  <Chevrons />
</AnimateIcon>
```
