## Usage

```tsx
import { Typer } from '@/components/sora-ui/texts/typer';

export default function Page() {
  return (
    <Typer
      className="font-semibold text-4xl tracking-tight"
      text="Type that assembles itself."
    />
  );
}
```

Cascade a stacked block, one line per string:

```tsx
<Typer
  text={['Type that', 'assembles itself,', 'one glyph at a time.']}
  stagger={0.15}
/>
```

Trigger declaratively with `trigger="in"`, `"out"`, or `"inout"`:

```tsx
const [trigger, setTrigger] = useState<'in' | 'out'>('in');

<Typer
  text="Declaratively controlled transition."
  trigger={trigger}
/>
<button onClick={() => setTrigger((prev) => (prev === 'in' ? 'out' : 'in'))}>
  Toggle
</button>
```

Scramble on hover:

```tsx
<Typer
  text="Hover over this line to scramble."
  triggerOnHover
/>
```

Narrow the pool of visual states each character rolls through:

```tsx
<Typer
  text="Only pills and accents."
  variations={['charFill', 'charAccentInverse', 'charBorder']}
/>
```

Recolor the fills, accent, and borders through props or CSS variables:

```tsx
<Typer
  text="Themed reveal."
  fg="#0b0b0c"
  bg="#ffffff"
  accent="#6d28d9"
  accentInk="#ffffff"
  border="#6d28d9"
  radius="8px"
/>
```

Render as a different element and control it imperatively:

```tsx
const handle = useRef<TyperHandle>(null);

<Typer ref={handle} as="h1" text="Controlled headline." startOnView={false} />
<button onClick={() => handle.current?.replay()}>Replay</button>
<button onClick={() => handle.current?.out()}>Clear</button>
```

## Accessibility

When `prefers-reduced-motion: reduce` is set, the reveal loop is skipped entirely: each line mounts fully visible as plain text with no state ripple, matching the CSS reduced-motion fallback. Imperative handle methods (`play()`, `replay()`, `in()`, `out()`, `reset()`) still resolve safely without driving animations.
