## Base UI Alert Dialog, Homepage Redesign & Button Physics Fix

  </ChangelogItemVersion>

<ChangelogItemTitle>UI Components & Motion</ChangelogItemTitle>

<ChangelogItemDescription>

- **Base UI Alert Dialog** (`/ui/base/alert-dialog`): Shipped accessible alert dialog modal with Motion 3D perspective spring transitions, backdrop blur, responsive sizes (`default` and `sm`), and `AlertDialogMedia` icon slot.
- **Button Subpixel Jitter Fix**: Eliminated font rasterization jitter and text displacement on hover scale across Base UI (`/ui/base/button`) and Radix UI (`/ui/radix/button`) by anchoring elements to GPU composite layers (`[backface-visibility:hidden]`, `will-change-transform`) with critically-damped spring damping.
- **MotionScore Grid Optimization**: Refactored the MotionScore Quality Framework cards in the UI Roadmap to a balanced 2-row desktop layout and 1-column mobile view for improved readability.

</ChangelogItemDescription>

<ChangelogItemTitle>Homepage & Navigation</ChangelogItemTitle>

<ChangelogItemDescription>

- **Homepage Redesign**: Shipped the all-new Sora UI homepage with interactive info sections, animated mascot, and streamlined responsive layouts.
- Cleaned animation easing tokens and purged legacy styles for better runtime efficiency.
- Synchronized 24px icon sizing across navigation bars and added graceful auth status indicators.

</ChangelogItemDescription>

<ChangelogItemTitle>Developer Experience & Docs</ChangelogItemTitle>

<ChangelogItemDescription>

- Added `NEXT_PUBLIC_ENABLE_AUTH` feature flag with graceful fallback handling and maintenance alert banners.
- Published beginner fast-track guide and comprehensive documentation for `@workspace/www-cli`.
- Updated UI Roadmap (`/ui/roadmap`) to include Base UI Alert Dialog in Phase 1.

</ChangelogItemDescription>

## Base UI Foundation, Accordion & Taxonomy Evolution

  </ChangelogItemVersion>

<ChangelogItemTitle>UI Foundation & Primitives</ChangelogItemTitle>

<ChangelogItemDescription>

- **Base UI Launch**: Released core `Button`, `Checkbox`, `Dialog`, and `Accordion` (`/ui/base/accordion`) primitives.
- Accordion features spring height morphing, bottom mask gradient fade, chevron spring rotation, and shared `layoutId` focus ring.
- Replaced conflicting CSS transitions with pure GPU compositor transforms across dialog overlays and interactive buttons.
- Standardized `prefers-reduced-motion` compliance across all components.

</ChangelogItemDescription>

<ChangelogItemTitle>Taxonomy & MotionScore™</ChangelogItemTitle>

<ChangelogItemDescription>

- **3-Tier Taxonomy**: Restructured the ecosystem into **Motion** (`/docs/motion`), **Catalog** (`/catalog`), and **UI** (`/ui`).
- **Interactive UI Roadmap & Timeline** (`/ui/roadmap`): Added roadmap tracking Base UI and Radix UI rollouts with MotionScore™ performance benchmarking guidelines.
- Dynamic Edge OG image generation support for `/ui` and `/catalog` routes.

</ChangelogItemDescription>

<ChangelogItemTitle>Infrastructure</ChangelogItemTitle>

<ChangelogItemDescription>

- Migrated Sora MCP server to `@xmcp/framework` (`apps/xmcp`) supporting STDIO and HTTP transports.

- Standardized automated Ultracite (Biome) lint-fixing in registry build workflows.
