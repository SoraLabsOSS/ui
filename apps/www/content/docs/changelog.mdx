## Base UI Accordion & XMCP

  </ChangelogItemVersion>

<ChangelogItemTitle>UI</ChangelogItemTitle>

<ChangelogItemDescription>

- New Base UI `Accordion` primitive (`/ui/base/accordion`) with spring height morphing, bottom mask gradient fade, chevron spring rotation, exit animation via `AnimatePresence`, and shared `layoutId` focus ring gliding.
- Added 4 interactive showcase variants (`default`, `bordered`, `separated`, `ghost`) with live documentation showcase.

</ChangelogItemDescription>

<ChangelogItemTitle>Infrastructure</ChangelogItemTitle>

<ChangelogItemDescription>

- Migrated Sora MCP server to `@xmcp/framework` (`apps/xmcp`) supporting STDIO and HTTP transports.
- Enhanced global native and WebKit scrollbars with adaptive dark mode styling.
- Standardized automated Ultracite (Biome) lint-fixing in registry workflows.

</ChangelogItemDescription>

</ChangelogItem>

## 3-Tier Taxonomy Evolution

  </ChangelogItemVersion>

<ChangelogItemTitle>Architecture</ChangelogItemTitle>

<ChangelogItemDescription>
