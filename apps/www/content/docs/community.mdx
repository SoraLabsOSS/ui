Sora UI spans a few places — each with a different job:

- **[GitHub repository](https://github.com/SoraLabsOSS/ui)** — bugs, questions, feature ideas, and roadmap threads.
- **[Blog](/blog)** — announcements, breakdowns, and longer-form updates from the team (not the place for support tickets).

<Callout>
  **Community hub:** [github.com/SoraLabsOSS/ui](https://github.com/SoraLabsOSS/ui) · **Blog:** [ui.soralabs.studio/blog](/blog)
</Callout>

## Blog

The [Sora UI blog](/blog) is where we publish **product news**, **announcements**, and **breakdowns** — how primitives are built, motion patterns we ship, registry changes, and what’s coming next.

Use the blog when you want to **read** what the team is sharing. Use GitHub when you want to **talk back** (questions, bugs, ideas).

Subscribe via [RSS](/blog/rss.xml) if you use a feed reader.

## Report a bug

If something in the docs, registry, or install flow is broken:

1. Check [Troubleshooting](/docs/troubleshooting) first.
2. [Open a new issue](https://github.com/SoraLabsOSS/ui/issues/new) on the repository.

Include when you can:

- Sora UI / component name (e.g. `@soralabs/accordion`)
- Steps to reproduce
- Expected vs actual behavior
- Environment (Next.js, React, Motion, Tailwind versions)

## Ask questions & discuss

For how-to questions, ideas, or general feedback, use **[GitHub Discussions](https://github.com/SoraLabsOSS/ui/discussions)**.

Introduce yourself, search existing threads, and pick the category that fits (question, idea, show-and-tell, etc.).

## What belongs where

| Goal | Where |
| --- | --- |
| Announcements, breakdowns, product updates | [Blog](/blog) |
| Bug in a component or docs | [New issue](https://github.com/SoraLabsOSS/ui/issues/new) |
| Question or idea | [Discussions](https://github.com/SoraLabsOSS/ui/discussions) |
| Roadmap & community meta | [GitHub repository](https://github.com/SoraLabsOSS/ui) |
| Docs content fix (PR) | Main Sora UI source repo (if you have access) |
