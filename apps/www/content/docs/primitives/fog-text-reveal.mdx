## Usage

```tsx
import { FogTextReveal } from '@/components/sora-ui/effects/fog-text-reveal';

export default function Page() {
  return (
    <FogTextReveal
      messages={[
        {
          top: ['The text fades in on its own,', 'one corner at a time.'],
          bottom: ['Then it clears the same way,', 'and quietly starts over.'],
        },
        {
          top: ['Type can move like weather,', 'rolling in from an edge.'],
          bottom: ['It gathers, holds for a beat,', 'then rolls back out again.'],
        },
      ]}
    />
  );
}
```

## When to Use

Use `FogTextReveal` for atmospheric hero cards, quote rotators, or feature callouts where a single self-contained surface should slowly breathe through a set of short messages. Pass one entry in `messages` with `loop={false}` for a one-shot reveal that settles and stays; pass several with `loop` for an ambient carousel of text.

Because the text is painted to a WebGL texture rather than laid out as flowing DOM, keep each line short and pre-wrapped — split copy into the `top` and `bottom` string arrays yourself rather than relying on automatic wrapping.

## Accessibility

The visible text lives on a `<canvas>`, so it is mirrored into a visually hidden `sr-only` element for screen readers and search engines. When `prefers-reduced-motion: reduce` is active, the animation loop never starts — the first message is drawn once, fully revealed and unblurred, and the card stays static. On devices without WebGL the canvas is skipped entirely and only the accessible text remains.
