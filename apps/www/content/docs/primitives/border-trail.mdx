## Usage

`BorderTrail` is a **client component** and decorative overlay. The parent must be `relative` with a matching `border-radius` (the trail inherits rounding via `rounded-[inherit]`).

```tsx
import {
  BorderTrail,
  BORDER_TRAIL_DEFAULT_GLOW,
} from '@/components/sora-ui/effects/border-trail';

export default function FeatureCard() {
  return (
    <div className="relative overflow-hidden rounded-xl border bg-card p-6">
      <BorderTrail size={100} style={BORDER_TRAIL_DEFAULT_GLOW} />
      <h3 className="relative z-[1] font-medium">Featured</h3>
      <p className="relative z-[1] text-muted-foreground text-sm">
        Your content sits above the trail.
      </p>
    </div>
  );
}
```

When `prefers-reduced-motion: reduce` is set, the loop is replaced by a subtle static ring. Pass `enabled={false}` to hide the effect entirely.
