## Usage

```tsx
import { TiltSlideTransition } from "@/components/sora-ui/catalog/tilt-slide-transition";

export default function PortfolioSection() {
  return (
    <div className="h-screen w-full">
      <TiltSlideTransition
        brandName="Sora"
        heroTitle="Sora"
      />
    </div>
  );
}
```

## Subcomponents

For granular multi-page or custom layout implementations, individual page views and the navbar can be imported separately:

```tsx
import {
  TiltSlideTransitionHome,
  TiltSlideTransitionProjects,
  TiltSlideTransitionInfo,
  TiltSlideTransitionNavbar,
} from "@/components/sora-ui/catalog/tilt-slide-transition";
```

## Starter Template

A standalone, ready-to-use Next.js starter template with this tilt-slide page transition pre-configured is available for cloning:

- **Demo**: [https://tilt-slide-template.soralabs.studio](https://tilt-slide-template.soralabs.studio/)
- **Repository**: [https://github.com/SoraLabsOSS/tilt-slide-template](https://github.com/SoraLabsOSS/tilt-slide-template)

```bash
git clone https://github.com/SoraLabsOSS/tilt-slide-template.git
cd tilt-slide-template
bun install
bun dev
```
