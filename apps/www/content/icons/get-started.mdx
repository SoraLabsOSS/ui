## Installation

Each animated icon is completely self-contained and installed directly via the shadcn CLI:

<CodeTabs
  codes={{
    npm: `npx shadcn@latest add @soralabs/icons-[icon-name]`,
    pnpm: `pnpm dlx shadcn@latest add @soralabs/icons-[icon-name]`,
    yarn: `npx shadcn@latest add @soralabs/icons-[icon-name]`,
    bun: `bun x --bun shadcn@latest add @soralabs/icons-[icon-name]`,
  }}
/>

For example, to install the `bell` icon:

```bash
npx shadcn@latest add @soralabs/icons-bell
```

## Basic Usage

Every icon is completely self-contained with built-in animation controls. It animates on hover by default:

```tsx
import { Bell } from "@/components/sora-ui/icons/bell";

export default function Example() {
  return (
    <div className="flex items-center gap-4">
      {/* Animate on hover (default) */}
      <Bell />

      {/* Control animation programmatically */}
      <Bell animate={isActive} />

      {/* Loop indefinitely */}
      <Bell loop />

      {/* Custom size and color */}
      <Bell size={28} color="#3b82f6" />
    </div>
  );
}
```

## API Reference

### Props

All icons accept standard SVG attributes alongside these motion props:

<TypeTable
  type={{
    size: {
      description: "Width and height of the icon in pixels (or any CSS length).",
      type: "number | string",
      required: false,
      default: "24",
    },
    color: {
      description: "Stroke color of the icon.",
      type: "string",
      required: false,
      default: "\"currentColor\"",
    },
    animate: {
      description: "Trigger the icon's primary animation programmatically.",
      type: "boolean",
      required: false,
      default: "false",
    },
    animateOnHover: {
      description: "Whether to play the animation when the user hovers over the icon.",
      type: "boolean",
      required: false,
      default: "true",
    },
    loop: {
      description: "Whether to repeat the animation continuously while triggered.",
      type: "boolean",
      required: false,
      default: "false",
    },
    className: {
      description: "Additional CSS classes to apply to the root SVG element.",
      type: "string",
      required: false,
    },
    "...props": {
      description: "Standard SVG motion props forwarded to the SVG element.",
      type: "SVGMotionProps<SVGSVGElement>",
      required: false,
    },
  }}
/>
